# Reports

Dated reports from the studio's analysts and researcher. One file per report, never edited after the session that wrote it (write a new one instead), so the folder is a history.

Names: `YYYY-MM-DD-analytics.md`, `YYYY-MM-DD-feedback.md`, `YYYY-MM-DD-research-<topic>.md`, `YYYY-MM-DD-pitch-<slug>.md`, `YYYY-MM-DD-qa-<slug>.md`.

Every report opens with three lines: what period or question it covers, where the data came from, and the one thing the Director should take from it. Numbers carry their dates and caveats.
