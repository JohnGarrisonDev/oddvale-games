# Ideas pipeline

Every game idea lives here, from a one-line spark to shipped. Newest at the top of each stage. Move rows between stages; don't delete rejected ideas, so nobody pitches them twice without new reasons.

Stages: **Spark** (one line, unresearched) → **Researched** (a research report supports it) → **Pitched** (a full pitch, see the designer role in README.md) → **Approved** (Director picked it, with reasons) → **Building** → **Shipped**. Or **Parked** / **Rejected**, with a reason.

Score researched ideas 1-5 on each: Fun in 10 seconds, Daily replay, Originality, Fits Oddvale, Phone friendly, Build size (5 = small). Note the total.

## Spark
Unresearched; the first research pass should test these against what's already out there.
- **Daily hole** for Wonky Putt: a generated or hand-made hole of the day with par and a share line. An update, not a new game.
- **A rhythm or timing game** with a daily track. The arcade has none.
- **A cooperative or pass-and-play puzzle** for two people on one device.
- **A deduction game with a daily mystery** (who took the parcel?), told through the odd robots.
- **A falling-sand or fluid toy with goals**, physics-heavy, with a daily challenge.
